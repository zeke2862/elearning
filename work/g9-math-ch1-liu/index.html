冒險筆記(課本重點)

二次函數:y = ax2 + bx + c,其中 a ≠ 0。

a > 0 開口向上,頂點是最低點;a < 0 開口向下,頂點是最高點;|a| 愈大,開口愈小。

二次函數對稱軸頂點
y = ax2x = 0(0, 0)
y = ax2 + kx = 0(0, k)
y = a(x − h)2x = h(h, 0)
y = a(x − h)2 + kx = h(h, k)

平移:y = ax2 向右平移 h、向上平移 k,得到 y = a(x − h)2 + k。向左或向下時,h、k 取負數。

已知頂點 (h, k):先設 y = a(x − h)2 + k,再代入另一點求 a。
