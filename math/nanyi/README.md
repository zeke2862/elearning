# 🎒 南一版數學樂園

國小一～六年級・南一版課本的互動數學遊戲，打開就能玩，電腦、平板、手機都可以。
**全部檔案都在本機執行，不連外、不需要網路。**

## 怎麼開始

直接用瀏覽器打開 `index.html`，選年級和學期。
（如果瀏覽器擋住本機檔案的功能，可以在這個資料夾開一個簡單的網頁伺服器，例如 `python -m http.server`，再開 `http://localhost:8000/`。）

## 🔤 國字加註：不加註／注音／拼音

- 首頁、每個年級頁上方、遊戲裡右下角的小圓鈕，都能切換 **不加註・注音・拼音**，選擇會被記住（一～二年級第一次打開預設為注音）。
- 加註畫在字旁邊，**不改變文字內容**，所以答題判斷、朗讀題目、月考測驗卷都不受影響。
- 讀音由 [pinyin-pro](https://github.com/zh-lux/pinyin-pro)（MIT 授權，已放在 `shared/`）判斷多音字，注音是從拼音自動轉換的。
- 台灣國語的校正：`shared/ruby-overrides.js` 裡有「字詞校正表」（例如車 ㄔㄜ、因為 ㄧㄣ ㄨㄟˋ、蘋果 ㄆㄧㄥˊ ㄍㄨㄛˇ）、「前後文規則」（數 ㄕㄨˇ／ㄕㄨˋ），以及台灣輕聲較少的處理。
- **自動轉換不保證 100% 正確**。發現讀錯的字詞，在 `ruby-overrides.js` 的 `WORDS` 加一行 `'字詞': '拼音'` 就會生效。已知限制：連接詞「和」一律唸 ㄏㄜˊ（課本多標 ㄏㄢˋ）。

## 📁 資料夾

| 資料夾 | 內容 |
|---|---|
| `index.html` | 選年級／學期，加註設定 |
| `grade1-1` … `grade6-2` | 一～六年級的上（`-1`）、下（`-2`）學期，共 12 本，每本約 8～10 個單元，每單元 3～4 關 |
| `fix-lab` | 數學故障修復局（找出常犯的錯誤並修好） |
| `shared` | 共用程式：加註（`ruby.js`、`pinyin-pro.js`、`ruby-overrides.js`）、月考測驗卷（`kg-exam.js`）、背景音樂（`bgm.js`）、期中／期末範圍切換（`nanyi.js`） |
| `docs` | 各年級原本的開發筆記與單元目錄（來源、範圍說明），僅供參考 |

每個年級頁上方可選「期中考範圍／期末考範圍／全冊」，下方有月考測驗卷（期中、期末、全冊總複習）。學習進度（星星）只存在這台裝置的瀏覽器裡，不會上傳。

## 與原始版本的差異

- 只保留南一版：移除康軒、翰林的版本切換與補充單元（共 32 個，原本放在各年級的 `extra.js`）。
- 移除所有會從外部網站載入的腳本與字型（原本會連到 `kuog88.github.io` 和 Google Fonts），功能改為本地版本。
- 資料夾改名：`gradeN` → `gradeN-1`（上學期），`gradeN-2` 不變。
- 「家長報表」和「萌寵」是外部腳本提供的功能，已不再載入（遊戲本身不需要它們）。

## 已知的小事

- 月考題庫（`exam-bank.js`）裡仍留有原本給康軒、翰林用的補充單元題目，但不會被抽到（試卷範圍只依南一單元計算）。
- 故障修復局（`fix-lab`）原本會參考家長報表的作答紀錄；本版沒有那份資料，只使用故障修復局自己的練習紀錄。
