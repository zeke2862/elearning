# 角色動畫素材流程：結論與使用手冊

> 目的：讓「角色圖片」變成「會動的對戰動畫」，並且在其他對話窗也能直接接手。
> 更新日期：2026-10-18｜狀態：已在對戰預覽頁（Artifact）完成示範，**尚未接進真正的 world-map.html**

---

## 1. 一句話結論

**用「純黑背景的 JPG」生圖 → 我用腳本自動去背 → 手臂繞著肩甲圓心連續旋轉，就得到「影片般」的揮劍。**
不需要透明 PNG，不需要逐格畫動畫。

---

## 2. 兩種素材，各有用途

| | A 四姿勢圖 | B 分層圖（身體＋手臂） |
|---|---|---|
| 內容 | 一張圖橫排 4 個姿勢：待機／揮擊／受擊／勝利 | 一張圖放 2 個零件：「沒有持劍手臂的身體」＋「持劍的手臂」 |
| 動畫方式 | 換圖（像翻書） | 手臂**連續旋轉**（像影片） |
| 擅長 | 表情、受擊、勝利、倒下 | 揮劍、蓄力、連擊、防禦 |
| 限制 | 動作固定 4 種 | 只有一種身體姿勢 |
| 輸出 | `pose-idle/attack/hit/win.png` | `body.png`、`arm.png` |

**混搭的前提（重要，踩過的坑）**：A 和 B 必須是**同一個造型、同一種握法**。
實測發現：A 是「雙手持劍」、B 是「單手持劍」，混用時攻擊瞬間握法會突然改變，看起來像換了一個人。
所以對戰預覽頁目前**預設只用 A**（`duel.html` 裡 `USE_RIG=false`），B 的程式與校準都保留，等 B 圖改成同樣握法再打開。
**建議搭配**：同一個角色的 A、B 用同一組參考圖與同一段「持劍方式」描述生成；握法一致後，攻擊用 B、受擊與勝利用 A。
**怪物／非人形**：用 A 就好，B 的手臂不一定適用。

## 3. 生圖規則（兩種都一樣）

這些是實測成功的關鍵，缺一個就容易失敗：

1. **背景：純黑（#000000），不要任何地面、陰影、漸層。** 您的工具只能出 JPG，黑底是最乾淨的去背方式。
2. **角色要有白色描邊**（和現有勇者一樣）。白描邊是我用來分開「角色」和「腳下泥土」的依據，也能讓邊緣不殘留黑邊。
3. **角色之間要留空隙**，不能互相碰到或重疊。
4. **腳下的泥土塊可以有**，我會自動去掉；但不要大片草地、岩石。
5. **角色風格、比例、服裝必須跟現有勇者一致**（把現有勇者圖當參考圖丟給生圖工具）。
6. 圖不用特別大，**寬 1500 px 以上**即可。

### 提示詞（整理版）

> ⚠️ 這是我依「實測成功的條件」整理的版本，不是您當初那一句原文。
> 您原本生出好結果的那一段提示詞更可靠，**請貼在下面的空格保存**。

**A 四姿勢：**

```
像素風格 RPG 角色設定圖，與參考圖同一個角色（髮型、服裝、武器、比例完全一致）。
一張圖由左到右橫排 4 個姿勢，每個姿勢完整全身、同樣大小、腳底在同一條水平線：
1 待機站立；2 揮劍攻擊（劍高舉過頭準備劈下）；3 受到攻擊（身體後仰、表情痛苦）；4 勝利（舉劍歡呼）。
角色朝右。每個角色都有白色外框描邊。
背景是純黑色 #000000，沒有地面、沒有陰影、沒有任何其他物件。四個姿勢之間留有明顯空隙，互不重疊。
```

**B 分層（身體＋手臂）：**

```
像素風格 RPG 角色零件圖，與參考圖同一個角色、同一個畫風、同一個比例。
一張圖放兩個零件，左右分開、互不接觸：
左邊：角色的身體（站立，朝右），但「持劍的那隻手臂從肩膀處完全拿掉」，肩膀位置露出圓形的肩甲接口；
右邊：那隻持劍的手臂，含肩甲、護腕、手套與劍，自然向右下伸出，劍朝右上。
所有零件都有白色外框描邊。背景是純黑色 #000000，沒有地面、沒有陰影。
```

> 握法要和 A 一致：若角色是**雙手持劍**，請改成「身體拿掉雙臂，露出兩側肩甲接口；右邊那組零件是『雙手握劍的兩隻手臂＋劍』」。
> 目前的 `rig.js` 以**單一轉軸**旋轉整組手臂，雙手握劍時兩手相距很近，像素風格下看起來仍自然；若不自然，再拆成前後兩層手臂。

## 4. 處理腳本（在 `tools/` 資料夾）

需要 Python 3 + `pillow numpy scipy`（`pip install pillow numpy scipy`）。
**在新對話窗**：把腳本和您的黑底圖一起丟給 Claude，說「請用這個腳本處理」即可。

| 腳本 | 用法 | 輸出 |
|---|---|---|
| `tools/cut_poses.py` | `python3 cut_poses.py 黑底四姿勢圖.png 輸出資料夾` | `pose-idle/attack/hit/win.png`（透明、同比例、腳底對齊、置中）、`hero-sheet.png`、`check-*.png` 檢查圖 |
| `tools/cut_rig.py` | `python3 cut_rig.py 黑底分層圖.png 輸出資料夾` | `body.png`、`arm.png`、`swing.gif`、`check-*.png` |

腳本做的事：亮度門檻去黑底 → 分出各塊 → 用白描邊分開角色與泥土 → 統一縮放比例 → 腳底對齊。
**`cut_rig.py` 印出的「轉軸／肩膀初值」只是參考**，真正的對位請用修改器的校準面板（見第 6 節）。

## 5. 揮劍動畫模組 `rig.js`

一個獨立的 JS 檔，不依賴任何套件，Artifact、遊戲、修改器都用同一份。

```html
<script src="rig.js"></script>
<script>
  // stage = 舞台元素（需要 container-type:inline-size，因為大小用 cqw 單位）
  var r = JBRig.create(stage, {
    body:'images/rig/body.png', arm:'images/rig/arm.png',
    params:{ height:35 },       // 只改想改的，其餘用預設
    x:'26%', bottom:'10%'       // 站位
  });
  r.swing(function(){ /* 劍落下的瞬間：扣血、震動、受擊 */ },
          function(){ /* 整個動作結束 */ });
  r.set({ slashAngle:70 });     // 即時改參數
  r.getParams();                // 取得目前所有參數
</script>
```

### 劍光

不是固定貼圖，是**逐幀記錄「劍尖」與「劍身近護手處」兩條軌跡，把中間面積填起來並漸淡**，所以永遠貼著手臂真正走過的弧線；速度、角度改了，劍光自動跟著變。

### 參數（全部是比例，所以任何畫面大小都通用）

| 參數 | 意義 | 預設 |
|---|---|---|
| `shoulderX / shoulderY` | 身體上「斷臂圓形」的圓心（佔身體圖寬／高） | 0.6945 / 0.40 |
| `pivotX / pivotY` | 手臂圖上「肩甲圓心」＝旋轉轉軸（佔手臂圖寬／高） | 0.165 / 0.482 |
| `armScale` | 手臂圖寬 ÷ 身體圖寬 | 1.86 |
| `height` | 身體高度（佔舞台寬 %） | 72（對戰畫面用 35） |
| `restAngle / raiseAngle / slashAngle` | 待機／舉劍／下劈角度（負＝往上，正＝往下） | 0 / −72 / 58 |
| `raiseMs / slashMs / backMs` | 三段動作毫秒 | 260 / 130 / 300 |
| `tipX/tipY, guardX/guardY` | 劍尖、護手在手臂圖上的像素位置（只影響劍光） | 545,167 / 332,372 |
| `trail` | 劍光開關 | 1 |

> 這些數值是針對**目前這一組** `body.png`/`arm.png`（312×900、576×488）量出來的。換新角色圖時，重新對位轉軸、劍尖即可。

## 6. 校準：怎麼自己調（不必找 Claude）

兩個地方，選一個：

1. **修改器 `config-editor.html` →「🗡️ 揮劍校準」**（有即時預覽）
   ① 按「🎯 顯示轉軸十字」→ ② 用「身體圓心 X/Y」把十字移到身體肩甲圓形的正中央 → ③ 用「手臂轉軸 X/Y」讓手臂的肩甲蓋在同一點 → ④ 按「⚔️ 揮一刀」檢查 → ⑤ 按最上面「💾 儲存到本機」試玩，或「⬇️ 下載 game-config.js」覆蓋上線。
2. **Artifact「揮劍動作實驗室」**：同樣的滑桿，調好按「複製設定」，把那一串貼給 Claude 即可。

**判斷對不對的標準**：0° 待機時，手臂肩甲要**剛好蓋住**身體上的圓形肩甲，看起來像同一個人的手；舉劍、下劈時肩甲不能在身體上滑動、不能露出第二顆肩膀。

## 7. 已解決的問題（踩過的坑）

| 問題 | 原因 | 解法 |
|---|---|---|
| 手臂像聳肩、像別人的手 | 轉軸放在手臂圖最左端，離真正的肩甲圓心差約 65px | 轉軸改為「肩甲圓心對身體圓形圓心」 |
| 劍光方向畫反 | 用固定貼圖旋轉，和手臂動作無關 | 改為逐幀取樣劍尖軌跡再填色 |
| 劍光有稜角 | 取樣點太稀（每幀一個） | 每幀之間再插 6 個點 |
| 分層揮劍和待機姿勢握法不同（雙手↔單手） | A、B 是兩張獨立生成的圖 | 對戰預設改回只用 A；B 之後要用「雙手持劍」重新生成 |
| 揮劍時角色變大 | 分層身體高度與待機姿勢圖不一致 | 對戰畫面 `height:35`（= 待機姿勢圖角色高度 33.9cqw） |
| 呼吸動畫時手臂沒跟著動 | 只有身體在縮放 | 呼吸動畫掛在「身體＋手臂」的共同容器 |
| 棋盤格 JPG 去背失敗 | 白描邊與背景融合 | 改用純黑底 |
| 腳下泥土被當成角色 | 與角色連在一起 | 用白描邊圍出的內部區塊判定角色，泥土在外面 |
| CSS 旋轉方向相反 | 螢幕座標 Y 向下 | 負角＝往上舉，正角＝往下劈 |

## 8.5 已接進真正的遊戲（`world-map.html` 對戰舞台）

2026-10-18 起，遊戲本體的對戰舞台已支援「四姿勢圖」，**依軍階**設定：

- 設定在 `game-config.js` 的 `poses`（修改器：「🎭 對戰姿勢圖」）。每個軍階 0～6 一組：`idle` 待機、`attack` 出招、`hit` 受擊、`win` 勝利。**檔名空白＝沿用原頭像**，所以可以一個一個軍階慢慢補。
- 目前只有軍階 0（皮甲新手）有，檔案在 `images/pose/rank0-*.png`。
- 出招時換成出招姿勢並衝向對手，被打的一方換受擊姿勢；被擊倒用受擊姿勢倒地、獲勝換勝利姿勢。對手在上方時圖片自動鏡像成面朝左。
- **所有軍階**（包含沒有姿勢圖的）都新增了：衝刺殘影、落在對手身上的弧形劍光。
- 新增軍階姿勢圖步驟：① 生圖（第 3 節）→ ② `tools/cut_poses.py` 切出四張 → ③ 改名 `rankN-idle/attack/hit/win.png` 放進 `images/pose/` → ④ 在修改器填入檔名 → ⑤ 下載 `game-config.js` 覆蓋。
- 姿勢圖的畫布統一是 320×380，腳底在 y=360；程式依此對齊腳底、放大到和頭像差不多大。
- 分層揮劍（`rig.js`）**尚未**接進遊戲，原因見第 2 節（握法需一致）。
- 同一天另外把預覽版的**新外觀**搬進對戰舞台：VS 登場畫面、新字體（霞鶩文楷＋Fredoka）、SVG 圖示、金藍配色名牌與血條殘影；**裝備列保留**。其他畫面（地圖、關卡、商店、背包、工坊、對戰大廳與結算）還是舊外觀，是下一步。
