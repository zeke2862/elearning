# 數學遊戲整合範本

這份文件教您怎麼把「登入學號、領代幣、回傳成績、手機自動縮放、音效背景音樂」這五個功能，加進任何一款新做好的數學遊戲 html 檔案裡。跟著底下的步驟複製貼上就好，不用每次都重新設計。

## 事前準備

1. 把三個共用檔案，跟您所有的數學遊戲 html 檔案放在**同一個資料夾**（例如 `math/`）：
   - `math-game-common.js`（登入身分／代幣／回傳成績）
   - `mobile-fit.js`（手機自動縮放滿版，不裁切）
   - `math-game-audio.js`（背景音樂／音效）

2. 找出新遊戲的三個東西，等一下要用到：
   - **主要內容的外層容器**是哪個 `<div>`（通常叫 `#game-container` 或 `.container`）
   - **開始一個關卡／主題**的函式是哪個（例如 `startLevel()`）
   - **一輪／一關結束、要顯示結果**的函式是哪個（例如 `endLevel()`、`showResult()`、`gameOver()`）

---

## 步驟一：把主要內容包進「自動縮放容器」

找到 `<body>` 開頭，把主要內容包進 `<div id="mg-fit-stage">`：

```html
<body>

<div id="mg-fit-stage">
<div id="game-container">
    ... 原本的遊戲畫面內容都不用動 ...
</div>
</div><!-- /mg-fit-stage -->

<script src="math-game-common.js"></script>
<script src="mobile-fit.js"></script>
<script src="math-game-audio.js"></script>
<script>
    ... 原本的 <script> 內容 ...
</script>
</body>
```

**重要**：如果主要容器的 CSS 有寫 `width:100%`（相對於外層滿版），要在 `#mg-fit-stage` 加上 `style="width:800px;"`（數字改成這個遊戲原本設計的寬度），不然自動縮放會抓不到正確尺寸：

```html
<div id="mg-fit-stage" style="width:800px;">
```

如果主要容器本身已經是固定 px 寬度（例如 `width:800px`），`#mg-fit-stage` 就不用加 `style`，直接 `<div id="mg-fit-stage">` 即可。

⚠️ 主要內容的 CSS 裡如果有 `100vh` / `100vw` 這種「跟著螢幕變動」的單位，也要拿掉或改成固定 px，不然自動縮放會失效（原因跟 mobile-fit.js 檔案開頭的說明一樣）。

## 步驟二：在 script 開頭加上「登入徽章 + 音樂設定」

緊接在 `<script>` 開頭（原本程式碼的最前面）貼上：

```js
MathGameCommon.renderIdentityBadge();

// 💡 背景音樂設定：把這個遊戲的「大關卡」代號跟音樂檔路徑對應起來。
// 左邊的代號（例如 easy/proper/關卡種類...）要跟你程式裡判斷關卡用的
// 變數值一致，右邊是音樂檔路徑，還沒有真的音樂檔可以先全部指到同一個
// 檔名頂著用。
MathGameAudio.setMusicMap({
    大關卡代號1: "./audio/xxx-bgm.mp3",
    大關卡代號2: "./audio/xxx-bgm.mp3",  // 🔶 之後換成專屬曲目
});

// 💡 音效設定：先不填，會自動用內建合成音效；之後有真的音效檔，
// 把對應那行的 // 拿掉、填上檔名即可。
MathGameAudio.setSfxMap({
    // correct: "./audio/sfx-correct.mp3",
    // wrong:   "./audio/sfx-wrong.mp3",
    // click:   "./audio/sfx-click.mp3",
    // win:     "./audio/sfx-win.mp3",
    // lose:    "./audio/sfx-lose.mp3"
});
MathGameAudio.bindClickSfx('button');  // 選到所有按鈕的 CSS selector，有其他可點擊元素（如卡片）可以加逗號補上
```

**怎麼決定「大關卡代號」？** 看這個遊戲原本就有的分類/難度/系列變數，例如：
- 有「初級/中級/高級」→ 就用 `easy` / `medium` / `hard`
- 有「真分數/假分數/帶分數」系列 → 就用 `proper` / `improper` / `mixed`
- 完全沒有分類，只有一輪 → 只設一個代號，例如 `main`

## 步驟三：在「開始關卡」的函式裡播放背景音樂

找到 `startLevel()`（或類似名稱）的函式，在裡面加一行：

```js
function startLevel(lvl) {
    currentLevel = lvl;
    // ...原本的重置分數/生命值等程式碼...
    MathGameAudio.playBgm(currentCategory);   // 👈 加這一行，currentCategory 換成你遊戲裡實際的「大關卡」變數
    // ...原本剩下的程式碼...
}
```

同一個大關卡連續呼叫 `playBgm()` 不會重新播放（不會卡一下、不會從頭開始），只有真的換到不同大關卡才會切歌，這樣聽起來才會有連續感。

## 步驟四：在「答對／答錯」的地方加音效

找到判斷對錯的地方（通常在 `checkAnswer()` / `submitAnswer()` 裡），在對/錯的分支各加一行：

```js
if (isCorrect) {
    MathGameAudio.playSfx('correct');   // 👈 加這一行
    // ...原本答對的處理...
} else {
    MathGameAudio.playSfx('wrong');     // 👈 加這一行
    // ...原本答錯的處理...
}
```

## 步驟五：在「結算畫面」加上勝負音效 + 回傳成績 + 代幣

找到顯示結算/結果畫面的函式（`endLevel()` / `showResult()` / `gameOver()`），比照這個範本改：

```js
function endLevel(isWin) {
    // ...原本切換畫面、顯示標題文字的程式碼...

    MathGameAudio.stopBgm();                      // 👈 加這行：結束時停掉背景音樂
    MathGameAudio.playSfx(isWin ? 'win' : 'lose'); // 👈 加這行：播放過關/失敗音效
    if (isWin) MathGameFX.confetti(document.getElementById('game-container')); // 👈 過關灑五彩紙花

    // 💡 加這一段：回傳這次的練習成績、依答對率自動發代幣
    // correct/total 換成這個遊戲實際「答對題數」跟「總題數」的變數
    MathGameCommon.finishAttempt({
        game: '遊戲名稱',              // 會出現在老師端的紀錄裡，取一個好辨識的名字
        mode: currentCategory,         // 大關卡/系列名稱（沒有的話可以省略這行）
        topic: `關卡${currentLevel}`,  // 這次是第幾關/哪個主題
        correct: 答對題數變數,
        total: 總題數變數
    }).then(result => {
        // result.gbitAwarded 這次拿到幾枚代幣
        // result.newBalance  目前代幣總數
        // 可以顯示在結算畫面上，例如：
        // document.getElementById('某個元素id').textContent =
        //     `🪙 這次獲得 ${result.gbitAwarded} 枚代幣（目前共有 ${result.newBalance} 枚）`;
    });
}
```

## 步驟六（選用）：加上視覺特效，讓畫面更生動

`math-game-fx.js` 提供不用自己刻動畫就能用的特效，先在 `<script>` 開頭引入並加上星空背景裝飾：

```html
<script src="math-game-audio.js"></script>
<script src="math-game-fx.js"></script>   <!-- 👈 加這行 -->
<script>
    MathGameCommon.renderIdentityBadge();
    MathGameFX.floatStars(document.getElementById('game-container'), 40);  // 👈 背景星空裝飾（數字是星星數量）
```

在**答對**的地方加粒子噴發：

```js
const rect = document.getElementById('game-container').getBoundingClientRect();
MathGameFX.burst(rect.left + rect.width / 2, rect.top + rect.height / 2);
// 也可以加一段飄浮文字，例如：
MathGameFX.popText(rect.left + rect.width/2, rect.top + rect.height/2, '✨ 答對！', null, '#00f3ff');
```

在**答錯**的地方加震動：

```js
MathGameFX.shake(document.getElementById('game-container'));
```

在**過關/完成**的地方灑紙花（已經寫在步驟五的範本裡了）：

```js
MathGameFX.confetti(document.getElementById('game-container'));
```

想讓按鈕滑鼠移上去會輕輕彈跳，在 `<style>` 裡加一行（`.你的按鈕class` 換成遊戲裡實際的按鈕 class 名稱）：

```css
.你的按鈕class:hover {
    animation: mgfx-bounce-btn 0.5s ease-in-out infinite;
}
```

## 完成後的檢查清單

- [ ] `<div id="mg-fit-stage">` 有包住主要內容，且頭尾標籤數量對得起來
- [ ] 四個 `<script src="...">` 都加了（common / mobile-fit / audio / fx），且**放在遊戲主程式 `<script>` 之前**
- [ ] `renderIdentityBadge()`、`setMusicMap()`、`setSfxMap()`、`bindClickSfx()`、`floatStars()` 都在主程式最前面呼叫了
- [ ] `startLevel()`（或同等函式）裡有呼叫 `playBgm()`
- [ ] 答對/答錯的地方都有呼叫 `playSfx('correct')` / `playSfx('wrong')`，也可以加上 `burst()` / `shake()`
- [ ] 結算畫面的函式裡有呼叫 `stopBgm()`、`playSfx('win'/'lose')`、`confetti()`、`MathGameCommon.finishAttempt()`
- [ ] 用瀏覽器打開測試：右上角有登入徽章、手機模擬畫面下內容不會被裁切、答題有聲音有特效、過關/失敗有回饋

## 之後要換真正的音樂/音效檔案時

1. 把 `.mp3` 檔案放進遊戲同一層的 `audio/` 資料夾
2. 打開遊戲 html，把 `setMusicMap()` / `setSfxMap()` 裡對應的路徑換成你的檔名（左邊代號不要動）
3. 存檔、重新整理網頁即可，不用改其他程式碼
