# 讓 mathtestjb2.vercel.app 的學習紀錄送到老師後台

## 為什麼後台沒收到
學生玩的是 **https://mathtestjb2.vercel.app**，它是從 GitHub 倉庫 **zeke2862/MATHTESTJB2** 自動部署的。
這個遊戲本身**沒有任何送紀錄到後台的功能**（它原本的 report.url 是空的），所以不管誰玩、玩多少，後台都收不到。
之前放進 `elearning/math/JB2-defense/` 的是另一份複本，學生沒有在玩它。

## 怎麼修
把 `MATHTESTJB2-後台紀錄同步.patch` 套用到 **MATHTESTJB2 倉庫的 main**，Vercel 會自動重新部署。
補丁只**新增 2 個檔案**（`js/jb2_record.js`、`js/sync-client.js`）並在 `index.html` 多載入它們，沒有改動遊戲本身。已確認可以乾淨地套用在最新版（e033703「補回每日登入獎勵」）上。

### 套用方式（交給負責 MATHTESTJB2 的 Claude 工作階段最簡單）
把下面這段話貼給它：

> 請把 `zeke2862/elearning` 倉庫裡 `math/JB2-defense/補丁/MATHTESTJB2-後台紀錄同步.patch` 套用到這個倉庫（用 `git am`），commit 後推到 main。套用後請在瀏覽器測試：學生登記學號、玩一關，確認 localStorage 出現 `keyagent_other_v1:學號`，並且有往雲端中繼站送出資料。

（或自己在電腦上：`git am MATHTESTJB2-後台紀錄同步.patch`。）

## 套用後會發生什麼
- 學生的學號沿用遊戲裡登記的那一個。
- 每玩完一關，結果（星數、次數、花的時間、答題數與答對數、各題型對錯）會送到雲端中繼站，格式跟 JB2 數靈召喚師一樣。
- **以前就玩過的學生**（例如 252068）：下次開啟遊戲，就會把存檔裡的每關星數與次數補送一份，老師馬上看得到他以前打到哪。（以前沒記答題數與秒數，所以補的只有星數與次數。）
- 後台會自動把「同一位學生在不同網站的 JB2 紀錄」合併：每關最高星、次數、秒數取較大值，所以不會跟 JB2 數靈召喚師的紀錄互相蓋掉。
- 老師報表（jb2-report.html、keyagent-progress.html）會在名字旁標出「🛡️ 也玩過數學保衛戰」。

## 另外建議（選做）：更新 Google Apps Script
根目錄 `雲端同步-Code.gs` 的 `mergeJb2_` 我補了一段，讓「🛡️ 也玩過數學保衛戰」的標記在合併時不會被較新的 JB2 紀錄洗掉。
**不更新也不影響星數與次數的合併**，只是標記有時會不見。要更新：把 `雲端同步-Code.gs` 整份貼回 Apps Script 編輯器 → 部署 → 管理部署作業 → 編輯 → 新版本 → 部署。
