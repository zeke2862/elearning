# 好友功能（看好友有沒有在線上）— 給「數學保衛戰」使用

> 這份說明是給保衛戰（GitHub 倉庫 MATHTESTJB2）的 AI／工程師照著做的。
> 好友名單跟 JB2 數靈召喚師**共用同一個 Supabase 專案、同一批資料表**，所以學生在 JB2 加的好友，到保衛戰也看得到，反過來也一樣；在線狀態也是兩邊通用（在任何一邊玩，好友都看到你「在線上」）。

## 一、先做一次：建立資料表
到 Supabase（專案網址 `https://qkejjznejmxcfiyxviid.supabase.co`）→ SQL Editor，把 **`JB2-好友與小屋-Supabase.sql`** 整份貼上執行。
（如果 JB2 那邊已經執行過，保衛戰**不用再做**。）

## 二、功能怎麼運作（用小學生都懂的比喻）
- **簽到板**：每位同學在線上時，每 45 秒在板子（`jb2_presence`）寫一次「我還在」。超過 100 秒沒寫，就當他離開了。
- **加好友要對方同意**：A 輸入 B 的學號 → 送出邀請 → B 按「同意」才成為好友。
- **不聊天**：只看得到「勇者名＋學號＋在線 🟢／離線 ⚪」，沒有任何自由輸入文字，比較安全。
- **老師開關**：全校關閉、封鎖個別學號，用 SQL 一行就能做（見 SQL 檔最下面）。

## 三、資料表（共 5 張＋2 個函式）
| 名稱 | 用途 |
|---|---|
| `jb2_presence(student_number, name, last_seen)` | 簽到板 |
| `jb2_friends(a, b, status)` | a＝送邀請的人、b＝被邀請的人；status＝`pending`／`ok` |
| `jb2_settings(key, value)` | `friends_enabled`、`visit_enabled`，值為 `'1'` 或 `'0'` |
| `jb2_blocked(student_number)` | 封鎖名單 |
| `jb2_homes` | JB2 小屋（保衛戰用不到） |
| `rpc jb2_ping(p_sid, p_name)` | 報到（時間由資料庫蓋） |
| `rpc jb2_friend_list(p_sid)` | 回傳我的好友：`friend, name, status, direction('in'/'out'), online, secs_ago` |

## 四、保衛戰要加的畫面
1. 在主畫面（或選單）加一顆按鈕 **`👥 好友`**，id 設為 `friendB`。
2. 按下去彈出面板，內容由下面的腳本產生（只需要一個 `<div id="frp"></div>` 當容器）。
3. 取得學號／勇者名的方式：保衛戰一定已經有「學生登記學號」的機制，請在腳本最上方的 `getMe()` 改成讀取那個值。

## 五、直接可用的腳本（存成 `friends.js`，在保衛戰頁面載入）
需要先載入 Supabase：`<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/dist/umd/supabase.js"></script>`

```html
<button id="friendB" onclick="BFriends.open()">👥 好友</button>
<div id="frpWrap" style="display:none;position:fixed;inset:0;background:#000a;z-index:99;align-items:center;justify-content:center">
  <div style="background:#fff;color:#222;border-radius:14px;padding:16px;width:min(94vw,520px);max-height:86vh;overflow:auto">
    <button onclick="BFriends.close()" style="float:right">✕</button>
    <h2 style="margin:0 0 8px">👥 好友</h2>
    <div id="frp"></div>
  </div>
</div>
<script src="friends.js"></script>
```

```js
/* friends.js — 數學保衛戰・好友（與 JB2 共用資料表） */
(function () {
  'use strict';
  var URL_ = 'https://qkejjznejmxcfiyxviid.supabase.co';
  var KEY_ = '【貼上跟 JB2 battle-vol2.html 裡 SUPABASE_ANON_KEY 一模一樣的那串（anon public key）】';
  /* ★ 只需要改這個：回傳目前登入的學號與勇者名 */
  function getMe() { return { no: String(localStorage.getItem('YOUR_STUDENT_NO_KEY') || ''), name: String(localStorage.getItem('YOUR_STUDENT_NAME_KEY') || '') }; }

  var sb = window.supabase.createClient(URL_, KEY_), cfg = null, blocked = false, list = [], timer = 0;
  var esc = function (s) { return String(s == null ? '' : s).replace(/[&<>"']/g, function (c) { return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]; }); };
  var me = function () { return getMe().no.trim(); };
  var ago = function (s) { s = +s; if (!isFinite(s)) return '還沒上線過'; if (s < 100) return '剛剛'; if (s < 3600) return Math.round(s / 60) + ' 分鐘前'; if (s < 86400) return Math.round(s / 3600) + ' 小時前'; return Math.round(s / 86400) + ' 天前'; };

  function loadCfg() {
    return Promise.all([sb.from('jb2_settings').select('key,value'), me() ? sb.from('jb2_blocked').select('student_number').eq('student_number', me()).maybeSingle() : Promise.resolve({})]).then(function (r) {
      if (r[0].error) { cfg = null; return; }
      var m = {}; (r[0].data || []).forEach(function (x) { m[x.key] = x.value; });
      cfg = { friends: m.friends_enabled !== '0' }; blocked = !!(r[1] && r[1].data);
    }).catch(function () { cfg = null; });
  }
  function ping() { if (document.hidden || !me()) return; loadCfg().then(function () { if (cfg && cfg.friends && !blocked) sb.rpc('jb2_ping', { p_sid: me(), p_name: getMe().name || me() }); }); }
  function fetchList() {
    return sb.rpc('jb2_friend_list', { p_sid: me() }).then(function (r) {
      if (!r.error) list = r.data || [];
      var b = document.getElementById('friendB');
      if (b) { var on = list.filter(function (f) { return f.status === 'ok' && f.online; }).length, q = list.filter(function (f) { return f.status === 'pending' && f.direction === 'in'; }).length; b.textContent = '👥 好友' + (on ? ' 🟢' + on : '') + (q ? ' 🔔' + q : ''); }
    });
  }
  function html() {
    if (!me()) return '<p>請先登記學號，才能使用好友功能。</p>';
    if (!cfg) return '<p>連線中…（或老師還沒建立資料表）</p>';
    if (!cfg.friends) return '<p>老師暫時把好友功能關起來了。</p>';
    if (blocked) return '<p>你的好友功能目前被老師暫停了。</p>';
    var ok = list.filter(function (f) { return f.status === 'ok'; }), inc = list.filter(function (f) { return f.status === 'pending' && f.direction === 'in'; }), out = list.filter(function (f) { return f.status === 'pending' && f.direction === 'out'; });
    var h = '<p>我的學號：<b>' + esc(me()) + '</b></p><p>好友學號 <input id="frNo" maxlength="12" style="width:120px"> <button data-fa="add">➕ 送出邀請</button></p>';
    inc.forEach(function (f) { h += '<p>🔔 <b>' + esc(f.name || f.friend) + '</b>（' + esc(f.friend) + '）想當你的好友 <button data-fa="ok" data-id="' + esc(f.friend) + '">✅ 同意</button> <button data-fa="del" data-id="' + esc(f.friend) + '">❌</button></p>'; });
    h += '<h3>我的好友（' + ok.length + '）</h3>' + (ok.length ? '' : '<p>還沒有好友，輸入朋友的學號試試看！</p>');
    ok.sort(function (a, b) { return (b.online ? 1 : 0) - (a.online ? 1 : 0); }).forEach(function (f) { h += '<p>' + (f.online ? '🟢' : '⚪') + ' <b>' + esc(f.name || f.friend) + '</b>（' + esc(f.friend) + '）' + (f.online ? '在線上' : ago(f.secs_ago)) + ' <button data-fa="del" data-id="' + esc(f.friend) + '">💔</button></p>'; });
    out.forEach(function (f) { h += '<p>⏳ 等待 ' + esc(f.name || f.friend) + ' 同意 <button data-fa="del" data-id="' + esc(f.friend) + '">取消</button></p>'; });
    return h;
  }
  var draw = function () { var e = document.getElementById('frp'); if (e) e.innerHTML = html(); };
  function add() {
    var no = (document.getElementById('frNo').value || '').trim();
    if (!no || no === me()) { alert('請輸入「別人」的學號'); return; }
    if (list.some(function (f) { return f.friend === no; })) { alert('他已經在你的名單裡了'); return; }
    sb.from('jb2_presence').select('student_number,name').eq('student_number', no).maybeSingle().then(function (r) {
      if (!r.data) { alert('找不到這位同學（他要先打開過 JB2 或保衛戰、登記學號）'); return; }
      sb.from('jb2_blocked').select('student_number').eq('student_number', no).maybeSingle().then(function (b) {
        if (b.data) { alert('這位同學暫時不能加好友'); return; }
        sb.from('jb2_friends').insert({ a: me(), b: no, status: 'pending' }).then(function (x) { alert(x.error ? '送出失敗，請再試一次' : '邀請已送出！'); fetchList().then(draw); });
      });
    });
  }
  document.addEventListener('click', function (e) {
    var b = e.target.closest('[data-fa]'); if (!b) return; var a = b.dataset.fa, o = b.dataset.id;
    if (a === 'add') add();
    else if (a === 'ok') sb.from('jb2_friends').update({ status: 'ok' }).eq('a', o).eq('b', me()).then(function () { fetchList().then(draw); });
    else if (a === 'del' && confirm('確定嗎？')) Promise.all([sb.from('jb2_friends').delete().eq('a', me()).eq('b', o), sb.from('jb2_friends').delete().eq('a', o).eq('b', me())]).then(function () { fetchList().then(draw); });
  });
  window.BFriends = {
    open: function () { document.getElementById('frpWrap').style.display = 'flex'; draw(); Promise.all([loadCfg(), fetchList()]).then(draw); clearInterval(timer); timer = setInterval(function () { if (document.activeElement && document.activeElement.id === 'frNo') return; fetchList().then(draw); }, 20000); },
    close: function () { document.getElementById('frpWrap').style.display = 'none'; clearInterval(timer); }
  };
  document.addEventListener('visibilitychange', function () { if (!document.hidden) ping(); });
  setTimeout(function () { ping(); fetchList(); }, 2000);
  setInterval(ping, 45000);
  setInterval(function () { if (!document.hidden) fetchList(); }, 90000);
})();
```

## 六、驗收清單（做完請逐項測）
1. 兩台電腦分別用學號 A、B 開保衛戰 → A 輸入 B 的學號送邀請 → B 看到 🔔 並按同意 → 兩邊都看到對方。
2. B 關掉分頁，約 2 分鐘後 A 的名單變成 ⚪「N 分鐘前」。
3. 在 Supabase 執行 `update jb2_settings set value='0' where key='friends_enabled';` → 面板顯示「老師暫時關閉」，且不再報到；改回 `'1'` 恢復。
4. 封鎖測試：`insert into jb2_blocked(student_number) values ('B學號');` → B 不能報到、A 也加不到 B。

## 七、注意事項（老實話）
- 沒有登入系統，學號是學生自己填的，所以理論上可以冒用別人學號（跟學號對戰一樣的信任程度）。班級小遊戲可接受；要更嚴格需改用 Supabase Auth＋RLS。
- `anon public key` 本來就設計成可以放在前端，不是密碼；**絕對不要**放 `service_role` key。
