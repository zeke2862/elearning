# 把你的遊戲接上「教師後台」

> 給自己做遊戲的同學。照著做完，老師就能看到你的遊戲：**是誰玩的、玩了幾次、最高分、花了多少時間、答對率**。
> 這份說明是照我們做好的「數靈召喚師（JB2）」整理的，裡面的程式碼都實際測試過，可以直接複製。

---

## 1. 先看懂整個流程（用寄信來想）

```
 你的遊戲 ──寄信──▶ Google 試算表（信箱）──▶ 老師的「教師後台」網頁（看信）
   │                   │
   │ 玩完一局就寄       │ 每一封信 = 一位同學一次的紀錄
   └── 信上寫著：學號、你的遊戲代號、成績
```

- **sync-client.js**：幫你寄信的「郵差」，不用自己寫，直接用。
- **學號**：信封上的收件人。沒有學號，老師就不知道這是誰的紀錄。
- **遊戲代號**：你幫自己的遊戲取的名字（例如 `mygame`），老師才分得出是哪一款遊戲。
- **教師後台**：老師的網頁，負責把信整理成表格。

---

## 2. 你的遊戲只要做 4 件事

- [ ] ① 把「郵差」`sync-client.js` 放進你的頁面
- [ ] ② 沒登入學號的人，**強迫**輸入學號
- [ ] ③ 每玩完一局，把成績記下來
- [ ] ④ 離開頁面時，再寄一次（避免最後一局沒送出去）

下面一步一步來。

---

## 3. 步驟 1：放進郵差

把 `sync-client.js` 放在你的網站資料夾（跟 `index.html` 同一層），然後在你的遊戲頁面加：

```html
<script src="../sync-client.js"></script>
```

> `../` 是「往上一層」。你的遊戲放在哪一層，就加減幾個 `../`，讓它找得到 `sync-client.js`。
> 在瀏覽器按 F12 看「主控台」，如果出現紅字 `sync-client.js 404`，就是路徑不對。

---

## 4. 步驟 2：強迫輸入學號

郵差有一個函式 `keyagentGetActiveStudentNumber()`，會告訴你「現在是誰在玩」。沒有的話，就請他輸入：

```js
function ensureStudent(done) {
  const no = keyagentGetActiveStudentNumber();          // 已經登入過就直接用
  if (no) return done(no);
  const v = (prompt('請輸入你的學號') || '').trim();
  if (!/^[A-Za-z0-9_-]{2,12}$/.test(v)) return ensureStudent(done);   // 格式不對就再問一次（不能略過）
  localStorage.setItem('keyagent_active_student',
    JSON.stringify({ studentNumber: v, verified: false }));
  done(v);
}
```

遊戲一開始就呼叫它，輸入完才開始玩：

```js
ensureStudent(() => { /* 這裡才開始你的遊戲 */ });
```

- `prompt` 是最簡單的小視窗。想做得漂亮一點，可以改成自己畫的輸入畫面（參考 `jb2-sync.js` 裡的 `gate()`）。
- 學號只會存在這台手機／電腦的瀏覽器裡，下次打開不用再輸入。

---

## 5. 步驟 3：記錄成績（最重要的一步）

每一局結束時呼叫 `keyagentUpdateOtherGame`：

```js
keyagentUpdateOtherGame('mygame', prev => ({
  totalPlays: (prev.totalPlays || 0) + 1,            // 玩了幾次
  bestScore:  Math.max(prev.bestScore || 0, score),  // 最高分
  lastScore:  score,                                 // 這一次的分數
  totalSecs:  (prev.totalSecs || 0) + secs,          // 累積練習秒數
  totalQ:     (prev.totalQ  || 0) + total,           // 累積作答題數
  totalOk:    (prev.totalOk || 0) + right,           // 累積答對題數
  lastAt:     Date.now()
}));
```

- `'mygame'`：**你的遊戲代號**。只用英文字母和數字，不要跟別人的重複。
- `prev`：上一次存的紀錄（第一次玩是空的 `{}`）。所以每個數字都要寫 `prev.xxx || 0`。
- 它會**自動**存到這台裝置，並在 2 秒內自動寄出，不用自己寫寄信的程式。

### 欄位的名字有規則（很重要！）

同一個學生可能用手機又用電腦玩，系統會把兩邊的紀錄「合併」。**合併時看名字決定誰留下**：

| 名字長這樣 | 合併時 | 適合放 |
|---|---|---|
| 開頭是 `best`、`total`、`max`，或剛好叫 `plays` | 取**較大的**（只增不減） | 最高分、累積次數、累積秒數、累積題數 |
| 其他名字（例如 `lastScore`、`lastAt`） | 取**較新的那一份** | 最近一次的結果 |

所以：**要「累積」的，名字請用 `total…` 開頭；要「最高」的，用 `best…` 開頭。**
不然換手機玩之後，你的紀錄可能被舊的蓋掉。

### 如果你的遊戲有很多關卡

用「一關一格」的方式記，跟 JB2 一樣：

```js
keyagentUpdateOtherGame('mygame', prev => {
  const stages = Object.assign({}, prev.stages);
  const s = stages[stageId] || {};
  stages[stageId] = {
    bestStars: Math.max(s.bestStars || 0, stars),   // 這一關最高幾星
    plays:     (s.plays || 0) + 1,                  // 這一關玩幾次
    pSecs:     (s.pSecs || 0) + secs,               // 這一關練習秒數
    totalQ:    (s.totalQ  || 0) + total,            // 這一關累積作答題數
    totalOk:   (s.totalOk || 0) + right             // 這一關累積答對題數
  };
  return { stages, lastId: stageId, lastAt: Date.now() };
});
```

這樣老師就能看到：**哪一關幾顆星、玩幾次、花多少時間、答對率**。

## 6. 步驟 4：離開頁面時再寄一次

在遊戲載入時加這一行（只要一次）：

```js
keyagentInstallPageHideSync();
```

意思是「同學關掉分頁或切走的時候，補寄一次」，最後一局才不會漏掉。

---

## 7. 練習時間怎麼算才公平

我們的規則（老師看到的就是這個）：

1. **只算「玩完一局」的時間。**
2. **切到別的程式或分頁的時間不算。**
3. **玩到一半直接關掉的那一局，整局不算。**
4. 一局最多算 30 分鐘（避免開著不動）。

程式（直接複製）：

```js
let T0 = 0, ACC = 0;                                  // T0：這一段從幾點開始；ACC：已累積的毫秒
function tStart()  { ACC = 0; T0 = Date.now(); }      // 一局開始時呼叫
function tPause()  { if (T0) { ACC += Date.now() - T0; T0 = 0; } }
function tResume() { if (!T0 && !document.hidden) T0 = Date.now(); }
function tTake()   { tPause(); const s = Math.min(1800, Math.round(ACC / 1000)); ACC = 0; return s; }  // 一局結束時呼叫，回傳秒數

document.addEventListener('visibilitychange',
  () => (document.hidden ? tPause() : tResume()));    // 切走就暫停，回來就繼續
```

用法：**一局開始** → `tStart()`；**一局結束** → `const secs = tTake()`，再把 `secs` 放進步驟 3 的紀錄。
中途關掉就不會呼叫 `tTake()`，這一局自然就不算。

## 8. 完整的最小範例（整份複製就能跑）

存成 `mygame/index.html`（旁邊上一層要有 `sync-client.js`）：

```html
<!doctype html>
<html lang="zh-Hant"><head><meta charset="utf-8"><title>我的遊戲</title></head>
<body>
<button id="win">我玩完一局</button>
<script src="../sync-client.js"></script>
<script>
const GAME_KEY = 'mygame';

/* 1) 學號：沒有就強迫輸入 */
function ensureStudent(done) {
  const no = keyagentGetActiveStudentNumber();
  if (no) return done(no);
  const v = (prompt('請輸入你的學號') || '').trim();
  if (!/^[A-Za-z0-9_-]{2,12}$/.test(v)) return ensureStudent(done);
  localStorage.setItem('keyagent_active_student', JSON.stringify({ studentNumber: v, verified: false }));
  done(v);
}

/* 2) 練習時間：只算「玩完一局」的時間，切出去的時間不算 */
let T0 = 0, ACC = 0;
function tStart() { ACC = 0; T0 = Date.now(); }
function tPause() { if (T0) { ACC += Date.now() - T0; T0 = 0; } }
function tResume() { if (!T0 && !document.hidden) T0 = Date.now(); }
function tTake() { tPause(); const s = Math.min(1800, Math.round(ACC / 1000)); ACC = 0; return s; }
document.addEventListener('visibilitychange', () => (document.hidden ? tPause() : tResume()));

/* 3) 一局結束：記錄並送出 */
function finishRound(score, right, total) {
  const secs = tTake();
  keyagentUpdateOtherGame(GAME_KEY, prev => ({
    totalPlays: (prev.totalPlays || 0) + 1,
    bestScore: Math.max(prev.bestScore || 0, score),
    lastScore: score,
    totalSecs: (prev.totalSecs || 0) + secs,
    totalQ: (prev.totalQ || 0) + total,
    totalOk: (prev.totalOk || 0) + right,
    lastAt: Date.now()
  }));
}

keyagentInstallPageHideSync();                         // 4) 離開頁面時補寄
ensureStudent(() => { tStart(); });                    // 輸入完學號才開始
document.getElementById('win').onclick = () => { finishRound(80, 8, 10); tStart(); };  // 示範：玩完一局，80 分、10 題答對 8 題
</script></body></html>
```

## 9. 怎麼確認有成功

1. 用手機或電腦打開你的遊戲，輸入學號，玩完一局。
2. 等 10 秒左右。
3. 請老師打開那份 **Google 試算表**的 `sync_queue` 工作表：應該多一列，**B 欄是你的學號**。
4. 點開 **C 欄**的內容，裡面找得到 `"other":{"mygame":{ ... }}`，你記錄的欄位都在裡面，就成功了。

### 沒成功的話，照順序檢查

| 症狀 | 可能原因 |
|---|---|
| 主控台（F12）紅字：`keyagentUpdateOtherGame is not defined` | `sync-client.js` 沒載入，路徑不對 |
| 試算表沒有新的一列 | 沒輸入學號；或是網路不通；或老師還沒設定好接收網址 |
| 有新的一列，但裡面沒有你的遊戲代號 | 你呼叫 `keyagentUpdateOtherGame` 時代號寫錯 |
| 紀錄一直被舊的蓋掉 | 累積的欄位名字沒用 `total…`／`best…` 開頭 |

## 10. 老師的後台能看到什麼（現況）

- **你的資料會自動進到 Google 試算表**，每次都是一列，內容是你記錄的所有欄位。
- 目前**有做成漂亮表格的只有 JB2**：`math/JB2/jb2-report.html`。它會讀 `jb2` 這個遊戲代號的資料，顯示：每位學生、每一關的星數、答對率、練習次數、練習時間，以及題型弱點。
- 你的遊戲代號跟 JB2 不同，所以**要讓老師的後台也顯示你的遊戲，需要老師再加一段**（讓報表讀你的代號）。
  **所以請把你的遊戲代號、你有記錄哪些欄位（例如 `bestScore`、`totalPlays`），告訴老師。**

> JB2 的報表是照這個樣子做的：先挑出「這位學生最新的一筆」，再把同一個人在不同裝置的紀錄合併，最後顯示成表格。你的遊戲欄位如果跟第 5 節一樣用 `total…`、`best…`、`stages` 的寫法，老師要接就會很快。

---

## 11. 規則（一定要遵守）

1. **只記學號和遊戲成績。** 不要記真名、電話、住址、生日、照片。
2. **學號要老實輸入自己的。** 不要輸入別人的學號，老師看到的就會是別人的紀錄。
3. **老師的密碼不要寫進你的程式，也不要上傳到網路。** 學生端不需要任何密碼。
4. **班級名單不要放進你的遊戲或 GitHub。** 名單只放在老師自己的電腦。
5. **不要亂改 `sync-client.js`。** 它是大家共用的，改壞了所有遊戲都送不出去。
6. 紀錄只存在你的**瀏覽器**裡（以及老師的試算表）。如果清除瀏覽器資料，這台裝置上的紀錄會不見，但老師那邊已經寄出的不會消失。
