# 數學保衛戰（MATHTESTJB2）要加「中文／泰文」教學說明時怎麼做

JB2 召喚師版已完成（見 project-notes.md 2026-11-26）。保衛戰是另一個倉庫，要照樣做時：

1. 複製 `math/JB2/explain-th.js`（翻譯器＋語言切換）與 `math/JB2/lessons-th.js`（小老師泰文）進保衛戰的 `js/`。
2. 保衛戰的教學說明文字出口（教學／小老師畫面）改成：
   - 顯示前先問 `JB2TH.lang() === 'th'`；
   - 是的話用 `JB2TH.say(中文說明)`，回傳 `null` 代表沒翻完整，就顯示中文；
   - 在畫面標題放 `JB2TH.langBar()`，並用 `JB2TH.onLang(fn)` 在切換時重畫。
3. 語言選擇存在 localStorage `jb2-lang`。保衛戰與 JB2 是不同網站，瀏覽器資料不共用，學生要各選一次。
4. 缺的句型加到 `explain-th.js` 的 `STEP2`／`HINT_TH`。
