# JB2 老師報表：第一次設定（只要做一次）

報表頁：`math/JB2/jb2-report.html`（網站上就是 `…/elearning/math/JB2/jb2-report.html`）

## 一、在 Google 設定「老師密碼」並重新部署
1. 打開你當初放同步資料的那份 Google 試算表 → **擴充功能 → Apps Script**。
2. 把專案裡的 `雲端同步-Code.gs`（在 repo 最外層）整份內容，貼上去**取代**原本的程式碼，按儲存。
3. 左邊齒輪 **專案設定** → 最下面 **指令碼屬性** → **新增指令碼屬性**：
   - 屬性：`JB2_TOKEN`
   - 值：自己取一組長一點的密碼（只有你知道，不要告訴學生）。
4. 右上 **部署 → 管理部署作業** → 點鉛筆 ✏️ 編輯 → 版本選 **新版本** → 部署。
   （一定要這樣更新舊的部署，網址才不會變。「誰可以存取」維持**所有人**。）

## 二、打開報表頁
1. 用瀏覽器開報表頁，點「⚙️ 設定」。
2. **接收網址**：貼上 Apps Script 的網址（`https://script.google.com/macros/s/…/exec`，跟 `sync-client.js` 裡那串一樣）。
3. **老師密碼**：貼上剛才的 `JB2_TOKEN`。
4. **班級名單**：選你的名單檔（Excel，第一列要有「班級、座號、學號、姓名」）。
5. 按「儲存並載入」。

> 名單、網址、密碼只存在**你這台電腦的這個瀏覽器**，不會上傳到網路（網站是公開的，所以名單不能放進網站）。換電腦或換瀏覽器要再匯入一次。

## 看得到什麼
每位學生：班級、座號、學號、姓名、勇者名、總星數、最後一關（幾星、哪種模式）、練習次數、練習時間、最後更新。
點一位學生展開：每一關的最高星、次數、花的時間、最近一次，以及弱點題型。
- 「還沒玩」：名單裡有、但還沒有任何紀錄的學生。
- 「名單外」：有紀錄、但學號不在名單裡（通常是學號打錯）。
- 可以下載 CSV。
