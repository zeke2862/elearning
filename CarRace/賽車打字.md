## 核心演算法 (Core Logic)### 1. TQC 標準 WPM 計算公式TQC 檢定通常以「淨 WPM」計算，打錯字需扣分。```javascript
// 淨 WPM = (總輸入字母數 / 5 - 錯誤單字數) / 時間(分鐘)
function calculateTQC_WPM(totalChars, wrongWords, timeElapsedSeconds) {
    const minutes = timeElapsedSeconds / 60;
    if (minutes === 0) return 0;
    const grossWpm = (totalChars / 5) / minutes;
    const netWpm = grossWpm - (wrongWords / minutes);
    return Math.max(0, Math.round(netWpm * 10) / 10);
}
```
### 2. 賽車推進力與動態補償 (黃旗機制)為防止落後學生放棄，引入動態加成：```javascript
function calculateCarSpeed(baseWpm, rank, totalPlayers = 50) {
    let boostFactor = 1.0;
    // 如果排名在後 30% (第36-50名)，觸發黃旗追趕機制
    if (rank > totalPlayers * 0.7) {
        boostFactor = 1.3; // 獲得 1.3 倍的推進力加成
    }
    return baseWpm * boostFactor;
}
```
